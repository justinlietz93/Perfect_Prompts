# Application Roadmap

v0.2 establishes the intended product foundation:

- human-first repository organization;
- native filesystem/GitHub usability without the application;
- Prompt Beacon single and batch query workflows;
- project/source/type/runtime/path filters;
- previews and open/copy/export actions;
- GUI add/remove operations against the real filesystem;
- incremental synchronization for external filesystem changes;
- Lamina-style Python application boundaries;
- native installation/launcher identity using the Perfect Prompts logo.

Future work should only be added when it strengthens this library workflow. Strong candidates are saved query sets, a context basket/bundle assembler, explicit relationship metadata between equivalent/related representations, and richer artifact metadata editing. None should replace direct filesystem access or require a proprietary document format.
