# License Selection

The template does not impose a license. Select one during initialization.

Supported initializer values:

- `cc-by-4.0`: Creative Commons Attribution 4.0 International.
- `all-rights-reserved`: no reuse license is granted beyond applicable law.

Confirm journal, arXiv, employer, funder, and third-party material requirements before release. Strict validation requires an active `LICENSE.txt` and matching metadata.
