# Publication Figures

Store each publication and decision figure as an individual file. Use stable names beginning with the claim or figure ID, for example:

```text
C003_fig02_orthad_transport_obstruction.pdf
```

Requirements:

- publication-legible labels and captions;
- exact mathematical meaning for every visual encoding;
- no overlapping or clipped text;
- no decorative pseudo-scientific geometry standing in for an argument;
- no notebook-only figures;
- source or deterministic regeneration path recorded in `validation/coverage.json` or `source_maps/`.

List figures used by the manuscript in `paper-source/ARXIV_FIGURES.txt`.
