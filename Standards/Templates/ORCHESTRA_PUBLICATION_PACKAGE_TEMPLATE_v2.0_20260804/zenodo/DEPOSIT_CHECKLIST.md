# Zenodo Deposit Checklist

Official documentation should be rechecked at deposit time:

- https://help.zenodo.org/docs/deposit/
- https://help.zenodo.org/docs/deposit/describe-records/reserve-doi/
- https://help.zenodo.org/docs/deposit/manage-files/
- https://help.zenodo.org/docs/deposit/manage-versions/

## Before upload

- [ ] Decide whether this is a draft, preprint, or final release.
- [ ] Reserve a DOI when it must appear inside the PDF before publication.
- [ ] Confirm the reserved DOI belongs to this exact object.
- [ ] Compile the final PDF after inserting the DOI.
- [ ] Run finalization and retain the external ZIP SHA-256.
- [ ] Use `paper.pdf` as the default preview when appropriate.
- [ ] Upload the full publication release ZIP; optionally upload `paper.pdf` separately for direct preview.
- [ ] Fill all relevant metadata, including creators, ORCID, affiliations, description, keywords, license, related identifiers, and version.
- [ ] Preview the record before publishing.
- [ ] Never silently replace significant published files; issue a new version.
