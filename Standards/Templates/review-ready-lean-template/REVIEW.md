# Review protocol

Run these commands from a fresh clone.

## 1. Build the project

```bash
lake build
```

## 2. Build the mirrored test library

```bash
lake test
```

## 3. Run repository hygiene checks

```bash
lake lint
```

## 4. Print axiom dependencies for flagship declarations

```bash
bash scripts/audit_axioms.sh
```

Inspect `Audit/axioms-report.txt`.

Green path:

- only built-in axioms such as `propext`, `Classical.choice`, or `Quot.sound`
- no `sorryAx`
- no unexpected custom axioms

## 5. Re-check built proofs from `.olean` files

```bash
lake exe lean4checker --fresh ReviewReadyTemplate
```

## 6. Build API documentation

```bash
bash scripts/build_docs.sh
```

## 7. Recompute manifest hashes if you changed review artifacts

```bash
python scripts/recompute_sha256.py
```

## Notes

- `Audit/AxiomAudit.lean` is the human-edited audit entrypoint.
- `Audit/AxiomAudit.generated.lean` is generated by the audit script.
- `docbuild/lake-manifest.json` should be committed once generated in a real project.
