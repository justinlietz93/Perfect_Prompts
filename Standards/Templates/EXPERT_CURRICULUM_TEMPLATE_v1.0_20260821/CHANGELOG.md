# Changelog

## 1.0 — 2026-08-21

Initial reusable curriculum template derived from the Phase Calculus / VDM curriculum architecture.

Preserved:

- one controlling progression order;
- primary spine plus exact-gated parallel branches;
- core/deepening/reference separation;
- capability-based exit gates;
- diagnostic acceleration;
- targeted prerequisite repair;
- current-work/research alignment without prerequisite drift;
- source-resource versus generated-work separation;
- group progress records;
- concept-transfer discipline.

Generalized:

- books to arbitrary resources;
- Brilliant to arbitrary diagnostic/rapid-exposure layers;
- Phase/VDM research mapping to arbitrary project/research transfer;
- mathematical proof requirements to domain-appropriate mastery evidence while preserving stronger research standards when applicable.

### Tooling included in v1.0

The template includes deterministic instantiation and validation tools. Filling a curriculum specification can scaffold group folders, populate exact exit gates/resources already present in the spec, and regenerate the controlling human-readable order without inventing educational content.
