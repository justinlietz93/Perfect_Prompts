# Research / Project Transfer Methods

This folder bridges curriculum learning into live research or project work.

If the standards library contains a canonical **Research & Evidence Standard**, that standard governs research-grade claims, proof, formal verification, computational experiments, provenance, figures, notebooks, and review. The records here are curriculum-facing transfer records, not a replacement research standard.

## Use these records to prevent conceptual drift

Before importing a concept from the curriculum into a project:

1. name the conventional concept;
2. cite the exact source and section;
3. record its definition and hypotheses;
4. work a standard example;
5. identify a counterexample or boundary case when useful;
6. state the proposed project counterpart independently;
7. classify the relationship honestly;
8. state the next verification step.
