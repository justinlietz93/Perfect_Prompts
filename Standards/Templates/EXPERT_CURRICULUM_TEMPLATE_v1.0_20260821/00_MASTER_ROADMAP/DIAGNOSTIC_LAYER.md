# Diagnostic / Rapid-Exposure Layer

Replace this with the actual diagnostic resources used by the curriculum: interactive lessons, placement tests, short surveys, flash problems, oral questioning, quick coding tasks, laboratory diagnostics, etc.

## Purpose

The diagnostic layer is for:

- rapid exposure;
- intuition;
- gap detection;
- checking whether elementary material is already usable;
- retesting a concept in another representation after repair.

It is not the proof, derivation, implementation, or deep-practice layer.

## Sampling rule

For each relevant topic:

1. attempt an early representative task;
2. attempt a middle representative task;
3. attempt the hardest accessible representative task;
4. skip forward when performance is clean and the reasoning can be explained;
5. stop and repair with the paired core resource when notation, derivation, transfer, execution, or explanation breaks down;
6. retest in a different representation after repair.
