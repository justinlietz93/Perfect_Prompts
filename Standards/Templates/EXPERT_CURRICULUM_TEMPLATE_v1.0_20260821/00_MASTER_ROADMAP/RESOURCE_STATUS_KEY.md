# Resource Status Key

- **OWNED / AVAILABLE** — already present in the curriculum resource library.
- **ACQUIRE** — obtain before or when the resource becomes active.
- **DIAGNOSTIC** — rapid sampling to expose gaps; does not control mastery by itself.
- **CORE PASS** — active study, practice, and exit-gate work; controls progression.
- **DEEPENING PASS** — second treatment after core command; normally does not block progression.
- **REFERENCE** — consult for live questions; do not read linearly by default.
- **OPTIONAL** — useful but not required for the gate.
- **RECREATIONAL / CONTEXTUAL** — broad intuition, history, narrative, biography, or motivation; may generate questions but does not become a premise merely by being memorable.

These roles are orthogonal to ownership. A resource can be `AVAILABLE + REFERENCE`, `ACQUIRE + CORE PASS`, etc.
