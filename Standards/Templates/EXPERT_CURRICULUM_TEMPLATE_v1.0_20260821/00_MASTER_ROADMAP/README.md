# Master Roadmap

This folder contains the curriculum-level state that must remain coherent across every group.

## Files

- `DEPENDENCY_GRAPH.md` — conceptual prerequisites and why they exist.
- `STRICT_ORDER_AND_START_GATES.md` — controlling order for the primary spine and every parallel branch.
- `MASTER_PROGRESS.md` — current active groups, milestones, gaps, and transfers.
- `RESOURCE_STATUS_KEY.md` — controlled meanings of resource roles.
- `RESOURCE_INVENTORY.md` — resources already available and where they are assigned.
- `RESOURCE_ACQUISITION_QUEUE.md` — acquisition order derived from the curriculum, never a competing recommendation order.
- `DIAGNOSTIC_LAYER.md` — how rapid survey / interactive / assessment resources are used.
- `SOFTWARE_BY_GROUP.md` — optional quick index for tools required by each group.

## Non-negotiable consistency rule

The dependency graph, start gates, acquisition queue, group READMEs, and `CURRICULUM_SPEC.json` must describe one curriculum, not five independently authored approximations of it.
