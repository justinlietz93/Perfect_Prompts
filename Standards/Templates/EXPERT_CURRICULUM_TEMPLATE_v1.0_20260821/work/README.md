# Work Tree

Generated learning artifacts belong here, not beside source resources.

Recommended structure for each active group:

```text
work/<group>/
├── notes/
├── exercises/
├── derivations/
├── notebooks/
├── figures/
├── experiments/
├── builds/
└── transfer/
```

Use only the subfolders that make sense for the domain.

The important invariant is source-resource separation, not the exact directory names.
