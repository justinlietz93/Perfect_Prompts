# Source Map

## Primary source architecture

This template was derived from the Phase Calculus and VDM curriculum package supplied on 21 August 2026. The source package established the following load-bearing patterns:

- one primary mathematical spine with a single controlling progression order;
- parallel application branches with explicit start gates rather than a second competing order;
- core-pass resources that control progression, with deepening and reference resources separated from the gate;
- a resource-acquisition queue derived from curriculum activation rather than independently ranked;
- group-local `README.md`, `PROGRESS.md`, `SOFTWARE.md`, and resource folders;
- diagnostic/interactive material used for rapid exposure and gap detection rather than as the proof/derivation layer;
- exit gates stated as capabilities;
- progress records covering independent problems, proof/derivation reconstruction, negative controls, and current research transfer;
- current-research alignment that prioritizes standard mathematics without assuming the research claims are already proved;
- targeted research-active bridges that repair the exact prerequisite blocking a live problem instead of demanding completion of the entire curriculum first;
- generated work kept separate from the source-resource folders.

## Generalization decisions

The reusable template changes subject-specific nouns without weakening the structure:

- `books` becomes `resources`;
- Brilliant becomes a generic diagnostic / rapid-exposure layer;
- Phase Calculus / VDM transfer becomes current-project / research transfer;
- mathematics-specific proof evidence becomes domain-appropriate independent reconstruction while preserving stronger formal/research requirements where applicable;
- physics/application branches become generic parallel branches;
- research-active symbolic-dynamics style activation becomes a generic targeted gap-repair mechanism.

## External standard boundary

Research-grade claim validation is deliberately not duplicated here. An instantiated curriculum should defer to the canonical Research & Evidence Standard in the standards library for proof, computation, provenance, formal verification, reviewer notebooks, figures, and adversarial review.
