# Reference Field Method

References are used to study **effects and mechanisms**, not to harvest plot pieces.

## For each reference, answer

1. What does this work make the audience assume?
2. What emotional effect does that assumption create?
3. When and how does the assumption change or fail?
4. What craft mechanism produces the effect?
5. What must this novel *not* copy from it?
6. What transferable principle remains after surface details are removed?

## Reference-field synthesis

After studying the references, write the shared craft essence in your own words.

Avoid: “My book is X meets Y.”

Prefer: “These works demonstrate several ways to achieve [specific reader effect], but this novel will achieve it through [its own mechanism].”

## Relevance test

A reference belongs here only if it helps answer a concrete craft question. Admiration alone is not enough.
