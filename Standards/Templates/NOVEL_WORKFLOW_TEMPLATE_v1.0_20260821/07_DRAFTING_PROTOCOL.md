# Drafting Protocol

## Draft order

Default order. Change it only for a reason.

1. Frame lock and reader contract.
2. Anchor/source scenes.
3. Coherent surface-life material.
4. Boundary or high-pressure scenes.
5. Separate difficult threads/frames if interleaving would cause confusion during composition.
6. Interleave only after each thread works locally.
7. Ending candidates / terminal pressure.
8. Final movement.

## Before drafting a chapter

Create a `CHAPTER_PACKET` containing:

- movement
- chapter purpose
- opening state
- closing state
- surface event chain
- active characters
- reader state
- scene cards
- required continuity facts
- motifs/source pressures available (not mandatory)
- banned moves
- unresolved questions

## During prose drafting

Prefer:

- behavior before explanation
- concrete surface before abstraction
- character-specific perception
- sensory causality
- dialogue that does social work, not theme delivery
- emotional consequences that persist

Avoid:

- characters announcing the novel's thesis
- explanatory prose added only because the author is afraid the reader will miss the design
- foreshadowing that advertises itself
- forcing source material into a scene just to satisfy a ledger

## Complex-frame rule

When a novel contains multiple timelines, viewpoints, realities, or narrative modes, draft them separately first when necessary. Establish local coherence. Interleaving is an editing problem after each stream can stand on its own.

## Prose updates planning

After each substantial draft section:

1. Record newly discovered facts.
2. Update characters/settings/continuity.
3. Mark outline assumptions that prose disproved.
4. Do not bend good prose to preserve a weak early outline.
