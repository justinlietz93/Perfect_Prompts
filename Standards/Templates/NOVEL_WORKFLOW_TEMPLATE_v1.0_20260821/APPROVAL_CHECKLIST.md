# Workflow Approval Checklist

Before using this template to build a new novel, approve or revise these workflow choices:

- [ ] Frame Lock is the highest artistic authority.
- [ ] Reader experience is planned explicitly, not inferred from plot alone.
- [ ] References are analyzed by craft function, not used as plot templates.
- [ ] 2–5 anchor scenes are drafted before the full outline is locked.
- [ ] Voice is calibrated from successful prose after anchor scenes exist.
- [ ] Structure uses macro movements → chapters/sequences → scene cards.
- [ ] Optional source artifacts are tracked as pressure, not literal adaptation requirements.
- [ ] Complex timelines/frames may remain locally valid instead of being prematurely reconciled.
- [ ] Prose discoveries are allowed to update the bible and invalidate weak outline assumptions.
- [ ] Revision uses explicit gates with pass/fail conditions.
- [ ] One canonical root/workbook is active at a time.
- [ ] Structural decisions use PROPOSED / ACTIVE / LOCKED / DEPRECATED statuses.
