## Evidence used to design this template

The template generalizes recurring package structure from the holistic Perfect Prompts skill audit, especially:

- `GAP_prompting_skill` — multi-mode activation and reference-template composition;
- `session_handoff_skill` — explicit package manifest, schema/reference use, executable validation;
- `comprehensive-data-analysis` — staged end-to-end capability with quality gates;
- `pdf` — dependency/environment and rendering requirements;
- `rigorous_research` — deep procedural package with supporting assets/references/scripts;
- `readme-generator.skill` — packaged script + reference architecture + SKILL entrypoint;
- runtime metadata under `agents/openai.yaml`.

No single source skill controls the template. The template preserves their common package-level invariants while leaving task-specific procedures open.
