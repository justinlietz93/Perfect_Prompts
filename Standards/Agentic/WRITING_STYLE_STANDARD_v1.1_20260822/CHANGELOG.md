# Changelog

## 1.1 - 2026-08-22

- Corrected public-nonfiction source precedence using explicit author preference rather than chronology.
- Promoted **The AI Tipping Point** to primary public / Medium style exemplar.
- Promoted **Curiosity is Not a Soft Virtue** to primary argumentative exemplar.
- Reclassified recent technical essays as specialized technical-explainer evidence rather than the default public voice.
- Replaced the paper-like public default with a hook-first conceptual Medium mode emphasizing distinctiveness, intellectual motion, accessible depth, thought experiments, and memorable framing.
- Added an explicit rule that rigor should live at the correct layer: public article for the idea and reader path; paper / tutorial notebook / code / data / Lean / appendices for the denser verification burden.
- Corrected the previous anti-grandeur rule: elevated historical, literary, mythic, or philosophical language is allowed when it meaningfully deepens the specific object.
- Added `research-paper mimicry in Medium articles` as an explicit anti-pattern.
- Updated collaborator rules, fast quality tests, quick reference, and source map accordingly.

## 1.0 - 2026-08-21

- Initial corpus-derived writing style standard.
- Separated public technical, argumentative, reflective, literary-fiction, and poetry modes.
- Added source precedence to prevent older writing from overriding current voice.
- Added cross-genre invariants, anti-patterns, editing passes, and AI/collaborator operating rules.
- Preserved project-specific literary frame laws as project authority rather than incorrectly generalizing them to all fiction.
