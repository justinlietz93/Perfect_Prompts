# Writing Style Standard

Current version: **1.1 (2026-08-22)**

This package is a corpus-derived and author-corrected writing standard. It separates the public Medium voice from specialized technical explainers, fiction, and poetry.

## Controlling public exemplars

1. **The AI Tipping Point** - default public / Medium conceptual voice.
2. **Curiosity is Not a Soft Virtue** - default argumentative voice.
3. Recent technical essays - specialized evidence for technical explanation, not the default article tone.

The central correction in v1.1 is that **explicit author preference outranks recency**. Public articles should aim to feel distinctive, thought-provoking, and difficult to stop reading. They should not be written as research papers with lighter formatting.
