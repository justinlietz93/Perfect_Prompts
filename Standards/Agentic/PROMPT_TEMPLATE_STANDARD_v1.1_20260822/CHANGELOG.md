# Changelog

## 1.1.0 — 2026-08-22

Major evidence-base correction after a holistic audit of Perfect Prompts.

- Rebased the standard on the full 580-file repository rather than primarily on the April 2025 prompt-template directory.
- Added the larger instruction-stack model: standards, methodologies, persistent AGENTS instructions, rulesets, personas, templates, state/context, tools/runtime, validation, and handoff.
- Added explicit boundaries for skills, profiles/current state, rulesets, and methodologies.
- Added context/state contracts and context-economy requirements.
- Added semantic parity requirements for Python/TypeScript/Rust/Go/plaintext and other runtime representations.
- Added persona and multi-agent composition rules.
- Added empirical-use requirements before canonical promotion.
- Reframed Guided Autonomy and ground-truth inspection as selectable methods rather than universal prompt procedure.
- Added anti-patterns for historical-authority-by-location, monolithic context dumping, projection promotion, runtime leakage, and methodology laundering.
- Added `PERFECT_PROMPTS_HOLISTIC_AUDIT.md`.

## 1.0.0 — 2026-08-22
