# Changelog

## v1.0.1 — 2026-08-21

- Corrected the notebook standard after explicit clarification of the intended reviewer experience.
- Established the paper notebook as a sequential reviewer tutorial (“tutorial island”), not a compressed machine-facing claim harness.
- Required narrative Markdown before claim demonstrations, readable figures/text outputs, strong explanatory code comments, and explicit bridges to Lean 4, SymPy, data, source code, and other evidence artifacts.
- Reclassified the Orchestra validator's blanket rejection of Markdown cells as an implementation defect that conflicts with the semantic notebook contract.
- Added concrete validator-remediation requirements so future Orchestra template revisions preserve rigorous executable checks without penalizing reviewer-facing exposition.

## v1.0 — 2026-08-21

- Consolidated the existing research-package, publication-validation, reviewer, formalization, curiosity-first, and curriculum research-method rules into one research-level standard.
- Made authority/custody, whole-claim integrity, claim architecture, burden mapping, provenance, negative controls, formal/symbolic/numerical evidence, figures, findings, review custody, closure, and concept transfer explicit.
- Preserved the current Orchestra research template as an implementation rather than replacing it.
- Separated research-package closure from publication closure.
- Recorded the live notebook conflict between CRAFT narrative-markdown scoring and the Orchestra claim-notebook validator instead of silently reconciling it.
- Added an adoption rule so this synthesis does not self-promote to canonical authority without user approval.
